# Nena Studio — Site

## Como usar
1. Substitui os ficheiros dentro de `imagens/` pelas tuas fotos reais, mantendo os mesmos nomes:
   - imagens/vela1.jpg
   - imagens/vela2.jpg
   - imagens/vela3.jpg
   - imagens/sobre.jpg
2. Abre `index.html` no browser (ou usa a extensão "Live Server" no VS Code) para pré-visualizar.
3. Faz commit e push para o GitHub como habitualmente.

## Estrutura
- index.html — página inicial
- loja.html — coleção completa de produtos
- sobre.html — história e missão da marca
- contactos.html — contactos e redes sociais
- css/style.css — estilos
- js/script.js — menu mobile, botão "Adicionar" e mensagens de feedback

## Notas
- O carrinho é apenas visual (mostra um contador e uma mensagem), não guarda dados nem processa pagamentos.
- Se quiseres vender a sério, o próximo passo é ligar a loja a uma plataforma de pagamentos (ex: Stripe) ou a um serviço como Shopify/WooCommerce.
